# uz-power-schedule (uz_power_schedule_android)

## Описание

Кроссплатформенное клиентское приложение на Python и Flet (Android / Windows) для мониторинга графиков почасовых отключений электроэнергии с официальных страниц Укрзалізниці. Приложение загружает HTML-страницы выбранного региона, извлекает расписание для указанной очереди (`1.1`–`6.2`) на текущие и следующие сутки, рассчитывает оставшееся время до следующего переключения и сохраняет последний успешный результат в локальный кеш для работы в офлайн-режиме.

Проект ориентирован на сборку автономного универсального Android APK с встроенным интерпретатором Python (`serious_python`) без внешнего бэкенда. Дополнительно в репозитории реализован набор сборочных и патч-скриптов для совместимости с различными версиями Android и мобильных графических драйверов.

## Технический стек

- **Python (`>=3.10`, встроенный runtime 3.12 на Android)**: основной язык бизнес-логики, сетевого взаимодействия, парсинга HTML и управления состоянием UI.
- **Flet (`0.85.1`)**: Python-фреймворк декларативного UI и клиент-серверная прослойка поверх Flutter.
- **Flutter (`3.41.7`)**: нативный графический клиент, формирующий Android-оболочку (`MainActivity : FlutterActivity`) и рендеринг интерфейса (через Skia / OpenGL ES).
- **serious_python (`1.0.0`) / serious_python_android (`1.0.1`)**: нативный мост (FFI + JNI), распаковывающий и запускающий CPython и `site-packages` внутри процесса Android-приложения.
- **requests и urllib3**: основной HTTP-клиент загрузки страниц УЗ с таймаутами и резервным обходом ошибок проверки SSL-сертификатов.
- **urllib.request и ssl (stdlib)**: резервный HTTP-клиент на случай недоступности или сбоя `requests`.
- **certifi**: пакет корневых CA-сертификатов, принудительно распаковываемый на Android (`extract_packages = ["certifi"]`).
- **BeautifulSoup4 (`bs4`)**: основной HTML-парсер таблиц расписания (`html.parser`); при отсутствии пакета используется встроенный регулярный парсер (`_parse_schedule_from_html_stdlib`).
- **chardet**: резервный детектор кодировки ответа сервера после перебора `utf-8`, объявленной кодировки, `windows-1251` и `cp1251`.
- **msgpack / httpx / anyio**: транспортная сериализация и асинхронный цикл событий в составе `flet==0.85.1`.
- **Gradle / Android Gradle Plugin / `desugar_jdk_libs:2.1.4`**: система сборки Android APK с поддержкой Core Library Desugaring и MultiDex.

## Ключевые особенности / Архитектура

- **IPC и протокол взаимодействия Flet**:
  - На Android Flutter-клиент (`build/flutter/lib/main.dart`) распаковывает `assets/flutter_assets/app/app.zip` и `libpythonsitepackages.so`, запускает Python через `SeriousPython.runProgram` и открывает Unix Domain Socket (`flet_<pid>.sock`); на Windows используется локальный TCP-сокет.
  - Версия Python-пакета `flet` в `pyproject.toml` и `requirements.txt` строго зафиксирована на `0.85.1`. Использование `flet>=1.x` недопустимо при Flutter-шаблоне `0.85.1`, так как в `flet 1.x` изменён формат кадрирования сокета (4-байтный префикс длины + байт типа фрейма), что приводит к бесконечному зависанию рукопожатия `RegisterClient` на экране запуска.
- **Рендеринг и совместимость с Android-устройствами**:
  - В `pyproject.toml` (`[tool.flet.android.meta_data]`) задано `"io.flutter.embedding.android.EnableImpeller" = "false"`. Это отключает движок Impeller (Vulkan) в Flutter `3.41.7` и переводит рендеринг на Skia (OpenGL ES), устраняя серый/пустой экран на устройствах с проблемными Vulkan-драйверами (в частности, Xiaomi / Redmi с HyperOS и MIUI).
  - Сборка настроена как единый универсальный APK (`split_per_abi = false`) с поддержкой `arm64-v8a`, `armeabi-v7a` и `x86_64`, с `useLegacyPackaging = true`, `multiDexEnabled = true` и отключённой минификацией (`minifyEnabled = false`, `shrinkResources = false`).
  - Скрипт `fix_desugaring.py` устанавливает глобальный Gradle init-скрипт (`~/.gradle/init.d/flet_desugaring.gradle`), включает `coreLibraryDesugaring`, очищает несовместимую версию `flet` в `build/site-packages` и патчит `serious_python_android` (`AndroidPlugin.kt` / проверка `SDK_INT >= 28` для `longVersionCode`).
- **Асинхронный конвейер данных и обновление UI**:
  - Загрузка выполняется неблокирующим образом через `asyncio.to_thread(fetch_url, url)` под защитой `asyncio.Lock` (`update_lock`), с таймаутами `(5, 10)` сек для `requests` и `10` сек для `urllib`.
  - Фоновая синхронизация (`auto_updater`) запускается каждые `AUTO_SYNC_INTERVAL_SEC = 300` секунд.
  - Таймер обратного отсчёта (`tick_timers`) опрашивается с шагом `1` секунда, но вызывает `page.update()` только при фактическом изменении текста или цвета статуса, исключая лишние перерисовки UI.
  - При фатальном исключении на старте `main(page)` перехватывает трассировку и выводит её на экран вместо молчаливого падения.
- **Парсинг и расчёт интервалов**:
  - Поддерживаются регионы `Дніпропетровська` и `Запорізька` (`REGIONS`), а также очереди `1.1`–`6.2` (`QUEUES`).
  - Функция `parse_intervals` связывает таблицы по заголовкам дат (`DATE_HEADER_REGEX`), объединяет отключения на стыке суток (`00:00` следующего дня) и определяет текущее состояние (`analyze_schedule_state`) с точностью до минуты.
- **Локальное хранилище**:
  - `get_persistent_data_dir()` выбирает доступный каталог с проверкой записи (кэшируя результат после разрешения `FLET_APP_STORAGE_DATA`) и сохраняет `uz_settings.json` и `uz_schedule_cache.json` с принудительным `flush()` и `os.fsync()`.
- **Структура файлов и текущее состояние модулей**:
  - Основной код приложения сосредоточен в `main.py` (точка входа `ft.run(main)`). Файлы `config.py`, `storage.py`, `parser.py` и `notifications.py` представляют собой выделенные модули ранней декомпозиции и не импортируются из `main.py`.
  - Системные уведомления отключены в активном UI и основном цикле; раздел настроек в интерфейсе отображает статус-заглушку `"В розробці"`.

## Требования

- **Операционная система для запуска desktop-версии**: Windows 10/11, Linux или macOS.
- **Операционная система для сборки APK**: Windows (поддерживается `build_apk.bat`) или Linux/macOS (`build_apk.sh`).
- **Python**: `>=3.10` (проверено на Python `3.11`).
- **Flet CLI**: строго `0.85.1` (`flet==0.85.1`, `flet-cli==0.85.1`).
- **Flutter SDK**: `3.41.7` (для сборки Android APK; скрипт `build_apk.bat` ищет SDK в `%USERPROFILE%\flutter\3.41.7\bin` или в `%USERPROFILE%\flutter\*`).
- **Android toolchain**: Java JDK 17, Android SDK (Build-Tools / Platform-Tools), устанавливается автоматически `flet build apk` при отсутствии или используется из локального окружения.
- **Целевые Android-устройства**: Android 5.0+ (API 21+) с архитектурой `arm64-v8a`, `armeabi-v7a` или `x86_64`.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd uz_power_schedule_android
```

2. Создайте и активируйте виртуальное окружение (опционально, но рекомендуется):

Windows (PowerShell):
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Linux / macOS:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установите зафиксированные зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите приложение локально на ПК для отладки и проверки UI:

```bash
python main.py
```

5. Соберите универсальный релизный Android APK:

На Windows (автоматический скрипт с предсборочным патчем `fix_desugaring.py`):
```bat
build_apk.bat
```

Либо вручную в PowerShell (Windows):
```powershell
python fix_desugaring.py
flet build apk --build-number 3
```

На Linux / macOS:
```bash
chmod +x build_apk.sh
./build_apk.sh
```

6. Готовый APK-файл будет создан по пути `build/apk/uz-power-schedule.apk`. Для чистой переустановки на Android при смене сборки предварительно удалите старую версию приложения с устройства, затем установите собранный APK.

## Управление / Использование

После запуска приложения взаимодействие осуществляется через графический интерфейс; дополнительных аргументов командной строки `main.py` не принимает.

- **Выбор региона и очереди**: два выпадающих списка (`Дніпропетровська` / `Запорізька` и очереди `1.1`–`6.2`). Смена значения немедленно сохраняет настройки в `uz_settings.json` и запускает загрузку актуального графика.
- **Кнопка `Оновити`**: принудительная синхронизация графика с сайта УЗ. При отсутствии сети отображается сохранённое расписание из `uz_schedule_cache.json` с пометкой `(кеш)`.
- **Кнопка `Поділитись ->`**: копирует текущий регион, очередь, интервалы отключений и строку таймера в буфер обмена устройства.
- **Иконка темы (солнце / луна)**: переключение между тёмной (`#111111`) и светлой (`#FAFAFA`) темами оформления с сохранением выбора.
- **Иконка настроек (шестерёнка)**: открывает/закрывает карточку настроек (в текущей ревизии отображается статус `"В розробці"`).

Консольные команды сборки и обслуживания:

```bash
# Проверка синтаксиса всех Python-модулей
python -m py_compile main.py config.py storage.py parser.py notifications.py fix_desugaring.py

# Применение патчей Gradle/AndroidManifest и очистка несовместимых site-packages
python fix_desugaring.py

# Сборка APK с указанием номера сборки
flet build apk --build-number 3
```
