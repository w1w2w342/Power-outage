# Графік відключень / Power-outage

**Power-outage** — кроссплатформенный мобильно-десктопный сервис на Python для оперативного отслеживания графиков стабилизационных и аварийных ограничений электроснабжения с автоматическим обновлением данных, динамическим таймером обратного отсчета и полноценной поддержкой работы без подключения к сети.

---

## 1. Концепция и назначение

* **Основная задача:** Автоматизация мониторинга ограничений подачи электроэнергии по очередям и подгруппам (от 1.1 до 6.2). Приложение исключает необходимость вручную искать таблицы на сайтах операторов, парсит актуальные данные, рассчитывает точное время до смены статуса и информирует пользователя.
* **Источники данных:** Официальные публикации графиков электроснабжения потребителей (на текущий момент интегрированы структуры региональных филиалов «Укрзалізниці» для Днепропетровской и Запорожской областей).
* **Сценарии применения:** Контроль ситуации дома и на работе, планирование бытовых задач и рабочего процесса с учетом графиков отключений.

---

## 2. Технологический стек

Архитектура приложения построена с разделением сетевого слоя, алгоритмов обработки временных интервалов и реактивного интерфейса:

| Компонент | Технология / Библиотека | Описание |
| :--- | :--- | :--- |
| **Язык разработки** | Python 3 | Базовая бизнес-логика, математика расчетных таймеров, обработка очередей и потоков. |
| **GUI & UI-фреймворк** | Flet 0.85.1 | Реактивный интерфейс на движке Flutter: адаптивная верстка под мобильные и десктопные экраны, аппаратные анимации и смена палитры. |
| **Сетевой клиент** | Requests | Сетевые HTTP/HTTPS-запросы к веб-ресурсам первоисточника для выгрузки сырых HTML-документов. |
| **Парсинг данных** | BeautifulSoup4 + re | Разбор структуры DOM, поиск таблиц нужного региона и выделение временных окон отключений регулярными выражениями. |
| **Кеширование и конфиг** | JSON (`uz_schedule_cache.json`) | Сериализация выбранных пресетов (`reg1`, `q1`, `reg2`, `q2`) и резервное сохранение последней валидной сетки расписания. |
| **Многопоточность** | Python threading | Фоновая загрузка, парсинг и посекундный тик таймеров в отдельных потоках без блокировки основного UI-цикла. |

---

## 3. Ключевые возможности

* **Мульти-слоты (Дом / Работа):** Независимый одновременный мониторинг двух различных адресов или очередей с быстрым переключением между вкладками.
* **Интеллектуальный статус-бар и таймер:**
  * Индикатор активного питания: расчет оставшегося времени до начала отключения в формате «Світло є. Вимкнуть через Xг Yхв» либо статус «Світло є до кінця доби».
  * Индикатор отсутствия питания: отсчет времени до расчетного восстановления электроснабжения («Немає світла. Увімкнуть через Xг Yхв»).
* **Офлайн-режим (Кеш):** При потере интернет-соединения или недоступности серверов сервис переключается на локальный кеш, сопровождая отображение меткой `(кеш)` и уведомлением в SnackBar.
* **Экспорт расписания («Поділитись →»):** Формирование текстового отчета по текущему статусу и временным слотам очереди в один клик с записью в буфер обмена для отправки в Telegram, Viber или SMS.
* **Адаптивные темы оформления:** Поддержка Light и Dark режимов с корректным контрастом карточек, текста и индикаторов состояния сети.
